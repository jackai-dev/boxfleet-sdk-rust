# BoxFleet Rust SDK (boxfleet_sdk)

> **Official SDK for BoxFleet (`boxfleet` / `boxfleek` / `jackai-box`)** — Generated by **[OmniWrap](https://omniwrap.dev)** from the canonical OpenAPI 3.1 contract (`openapi/boxfleet.openapi.yaml`) and qualified inside a live **E2B Firecracker MicroVM** via BoxFleet.

- **Organization**: [`https://github.com/orgs/jackai-dev`](https://github.com/orgs/jackai-dev)
- **Repository**: [`https://github.com/jackai-dev/boxfleet-sdk-rust`](https://github.com/jackai-dev/boxfleet-sdk-rust)
- **Umbrella Index & MCP/Skill Hub**: [`https://github.com/jackai-dev/boxfleet-sdk`](https://github.com/jackai-dev/boxfleet-sdk)
- **Control Plane & Website**: [`https://boxfleet.io`](https://boxfleet.io)

---

## Installation

```bash
cargo add boxfleet_sdk --git https://github.com/jackai-dev/boxfleet-sdk-rust
```

## Quick Start

```rust
use boxfleet_sdk::{Client, ClientConfig};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = Client::new(
        ClientConfig::new("https://boxfleet.io").with_bearer_token("bf_live_...")
    )?;
    let catalog = client.cloud().get_white_label_cloud_catalog().await?;
    println!("{:?}", catalog);
    Ok(())
}
```
